# Experiment 8: Cyclomatic Complexity of a Flow Graph

**Tools:** RAPTOR

## Aim
To complete: cyclomatic complexity of a flow graph.

## Procedure
Draw a flow graph with sequential nodes and decision branches. Calculate M = E − N + 2P (for one connected component, P=1).

## Sample result
```text
Sample graph: E=7, N=6, P=1; M=7−6+2=3.
```
