# Lab Experiments — GitHub Deliverables (30 Experiments)

This repository contains a folder for each of the first 30 experiments in the supplied lab list. Each folder includes an experiment README, relevant starter files where applicable, and a `results/result-preview.png`.

## Important note about screenshots
The PNGs are **illustrative result previews** created for documentation. They are not captured from your Jira, Figma, GitHub, Docker Hub, Jenkins, Kubernetes cluster, or cloud account. For final lab evidence, repeat the procedure in the actual tool and replace each preview with your own screenshot (keep the same filename). Do not submit a preview as proof of a live deployment.

## Repository layout
- `01-.../` through `30-.../`: experiment-specific deliverables
- Each folder: `README.md`, `results/result-preview.png`, plus source/config files for code and DevOps experiments
- `screenshots/`: contact sheet of all 30 result previews

## Suggested GitHub upload
1. Extract this ZIP.
2. Create a new GitHub repository.
3. Upload the extracted files or use `git init`, `git add .`, `git commit -m "Add 30 lab experiment deliverables"`, and `git push`.
4. Replace preview images with genuine screenshots as you perform each lab.
